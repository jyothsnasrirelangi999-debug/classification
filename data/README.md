# Dataset

Put the extracted file here as `creditcard.csv`. Expected columns: `Time`, `V1` to `V28`, `Amount`, and `Class`. The original CSV is about 151 MB and is ignored by Git.

Source: [ULB Credit Card Fraud Detection on Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud). Review its terms before redistribution.
